근로계약 종료 후 1개월 이내에 반드시 관할 고용센터에 구직등록을 마쳐야 하며, 구직등록일로부터 3개월 이내에 새로운 사업장과 근로계약을 체결하고 관할 출입국에 근무처 변경 허가를 완료해야 합니다. 기한 초과 시 합법 체류 신분이 박탈됩니다.

사업주의 귀책사유(임금체불, 폭언·폭행, 근로계약 조건과 현저히 다른 근로 제공, 사업장 휴폐업 등)가 입증되는 경우에는 사업주의 동의 없이도 고용센터 직권으로 사업장 변경이 가능합니다. 다만 단순 변심이나 협의되지 않은 이탈은 이적동의서가 필요하므로 사전에 공인행정사의 법적 사실관계 검토가 권장됩니다.
국립국제교육원에서 주관하는 TOPIK(한국어능력시험) 성적표 또는 법무부 사회통합프로그램(KIIP) 평가 단계가 공식 인정됩니다. 기본 배점 충족을 위해서는 최소 TOPIK 2급(또는 KIIP 2단계 이수) 이상이 필요하며, 고득점일수록 총점 경쟁에서 우선 선발될 확률이 크게 높아집니다.
근무 시작 전에 반드시 대학 유학생 담당자의 확인을 받은 '시간제 취업 확인서'와 사업주 근로계약서를 구비하여 관할 출입국관리사무소에 사전 '체류자격 외 활동허가'를 받아야 합니다. 사전 허가 없이 근무할 경우 불법취업으로 간주되어 강제퇴거 또는 비자 연장 불허 처분을 받게 됩니다.
